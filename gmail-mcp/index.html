gmail-mcp

A personal, local Model Context Protocol (MCP) server for read-only Gmail search.

What it is

gmail-mcp is a small Python program that runs on its owner's own computer. It lets Claude Code search and read messages in the owner's Gmail accounts so that questions like “when did I order the dishwasher?” can be answered from mail across several mailboxes at once.

Who it is for

This application is private. It is used only by its author, Albert Collver, with his own Google accounts. It is not offered to the public, is not distributed, and has no users other than its owner.

What it accesses

  • Google scope requested: https://www.googleapis.com/auth/gmail.readonly only.
  • It can search and read mail. It cannot send, delete, label or otherwise modify anything.
  • All processing happens locally on the owner's Mac. No mail content is sent to any server other than Google's Gmail API.
