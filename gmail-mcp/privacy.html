gmail-mcp Privacy Policy

Effective 19 October 2026

Scope of this application

gmail-mcp is a personal tool written and used by one person, Albert Collver, to search his own Gmail accounts. It is not a public service. The only Google accounts that use it belong to its author.

Data accessed

gmail-mcp requests a single Google OAuth scope, gmail.readonly. With that permission it can list, search and read messages, threads and attachments in the authorised mailbox. It cannot send, modify or delete mail, and it does not request access to any other Google service.

How data is used

Mail is read only in response to a search or read request made by the author inside Claude Code. Results are shown to the author and used to answer his question. Nothing is used for advertising, profiling, analytics or any other purpose.

Storage and sharing

  • OAuth refresh tokens are stored in files on the author's own computer, readable only by his user account.
  • Mail content is not stored by gmail-mcp. It is fetched from the Gmail API on demand and held in memory only for the duration of the request.
  • No mail content, tokens or personal data are transmitted to any third party or to any server other than Google's Gmail API.
  • No data is sold or shared with anyone.

Google API Services User Data Policy

gmail-mcp's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, or by deleting the token files on the author's computer.

Contact

Questions about this policy: collverab3@gmail.com.
